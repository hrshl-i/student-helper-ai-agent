# Student Helper AI Agent

## Project Objective

The Student Helper AI Agent is a beginner-friendly Python project designed to assist students with simple calculations, study tips, and basic questions.

## Features

- Performs simple mathematical calculations
- Provides study tips
- Answers basic student questions
- Uses separate Python functions for different tasks
- Provides an interactive command-line interface

## Technologies Used

- Python 3.13
- Visual Studio Code
- Git
- GitHub
- GitHub Copilot

## How to Run

Open the project folder in VS Code and run:

    py agent.py

## Example

    Please choose one of the following options:
    1 - Perform a calculation
    2 - Get study tips
    3 - Ask a basic question
    exit - Quit the agent

For a calculation, choose option 1 and enter an expression such as:

    2+2

The agent returns:

    Result: 4

## AI Assistance

GitHub Copilot was used as an AI coding assistant to generate the initial Python agent structure and functions.

All AI-generated code was reviewed and tested before being included in the project. AI contributions are documented in `CONTRIBUTION_LOG.md`.

## Limitations

This is a simple educational AI-agent project. It does not use an external large language model API and can only perform the functions implemented in the program.
